# Образ целевого результата через 12 месяцев

Данный документ описывает целевой образ архитектуры данных по завершении программы миграции, определяя границы систем, объемы данных и критерии успешности проекта.

## Целевой ландшафт данных

| Параметр | Целевое решение | Критерий успешного завершения |
| :--- | :--- | :--- |
| **Состав целевых систем** | FU CRM, Core, Cards, Loans, Customer MDM, Product/Reference MDM, Integration Layer, DWH, Lakehouse, BI, DataHub. | Для всех систем назначены владельцы, утверждены SLO, настроены мониторинг, процедуры резервного копирования и аварийного восстановления. |
| **Вывод из эксплуатации** | Системы RB (CRM, Core, Cards, Loans, DWH, BI) и все прямые интеграции, заменены в ходе миграции. | Отсутствие активных потребителей и производителей данных; проверен архив в режиме только чтение; отозваны все доступы и лицензии. |
| **Объем миграции** | Клиенты, согласия, обращения, договоры, продукты, счета, карты, кредиты, транзакционные операции и необходимая история. | Подтверждение полноты и целостности через сверку и бизнес-валидацию владельцами данных. |
| **Трансформация потоков** | Замена интеграций RB на стандартизированные API, событийную модель и управляемые конвейеры. | Новый маршрут успешно прошел этап параллельного запуска; старые потоки остановлены и переведены в режим мониторинга. |
| **Модель отчетности** | **DWH:** сертифицированная отчетность. <br>**Lakehouse:** полная история событий и транзакций. | Согласованные бизнес-метрики; наличие прослеживаемости до первоисточника; воспроизводимость закрытия периодов. |
| **Управление данными** | Децентрализованное управление через доменных владельцев, использование каталога, классификацию, контроль качества. | Наличие у критичных наборов данных владельца, контракта, прослеживаемости, политик доступа и установленных SLO. |

## Критерии завершения программы

Программа миграции считается успешно завершенной при выполнении следующих условий:

1.  **Целостность профилей:** 100% активных клиентов имеют уникальный глобальный идентификатор (Global ID); все спорные связи переведены в управляемую очередь на обработку и не объединены автоматически.
2.  **Финансовая точность:** Отсутствие необъяснимых расхождений в финансовых показателях в разрезе валют, бизнес-дат и статусов операций.
3.  **Стабильность сервисов:** Клиентские сервисы демонстрируют соблюдение всех согласованных SLO в течение установленного периода стабилизации.
4.  **Валидация отчетности:** Регуляторная и управленческая отчетность успешно принята владельцами в течение двух последовательных финансовых периодов закрытия.
5.  **Завершение жизненного цикла устаревших систем:** Для каждого выводимого из эксплуатации компонента утверждены процедуры архивации, сроки хранения, границы отката и подписан акт о выводе из эксплуатации.
