# Реестр рисков миграции

Данный реестр содержит идентификацию, оценку и стратегии реагирования на риски, возникающие в процессе миграции данных и систем.

| Риск | Влияние | Вероятность | Меры по снижению рисков |
| :--- | :--- | :--- | :--- |
| **Ошибочное слияние клиентов** | Нарушение конфиденциальности (раскрытие ПДн), некорректное применение продуктов и услуг. | Высокая | Применение консервативных порогов сопоставления, обязательный ручной аудит, механизмы аудита и процедуры разделения записей. |
| **Потеря или дублирование финансовых записей** | Искажение остатков на счетах, ошибки в финансовой отчетности. | Средняя | Обеспечение идемпотентности процессов, использование неизменяемого слоя, контроль через счётчики, кеши, итоговое показатели; остановка процесса переключения при расхождениях. |
| **Изменения в системах в ходе миграции** | Конфликты версий данных и нарушение целостности. | Высокая | Жесткий период заморозки изменений, проверка версий, возможность повторной обработки. |
| **Низкое качество исторических данных RB** | Неполнота профиля Customer 360, рост операционных рисков. | Высокая | Предварительное профилирование, присвоение оценок качества, ограничение использования данных, исправление данных на стороне источника. |
| **Избыточная нагрузка на OLTP при извлечении данных** | Деградация производительности клиентских сервисов и каналов. | Средняя | Проведение нагрузочного тестирования, использование реплик для чтения, ограничение скорости. |
| **Недостаточная производительность MDM** | Задержки в процессах обслуживания клиентов. | Средняя | Тестирование емкости, обеспечение высокой доступности (HA), использование кэша для чтения, очереди на запись, наличие плана отката. |
| **Расхождение отчетности FU и RB** | Невозможность закрытия финансового периода. | Высокая | Использование единого глоссария метрик, параллельное закрытие периодов, процедура сверки, официальное утверждение финансовым департаментом. |
| **Невоспроизводимый откат** | Продолжительный простой критических бизнес-процессов. | Низкая / Высокий ущерб | Проведение репетиций в среде, идентичной продуктовой, тестирование восстановления из архивов, наличие четких инструкций и назначенных ответственных. |
| **Дефицит компетенций и ответственности** | Принятие некачественных решений и срыв сроков проекта. | Высокая | Назначение ответственных владельцев, программы обучения, использование шаблонных архитектурных решений, ограничение объема MVP. |
