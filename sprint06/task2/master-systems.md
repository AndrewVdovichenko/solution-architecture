# Матрица систем управления данными

Рассмотрим несколько систем:

- **Система ввода (System of Entry/SoE)** осуществляет первичную регистрацию данных.
- **Система учета (System of Record/SoR)** является владельцем юридически и операционно значимой записи.
- **Мастер-система (Master System/MS)** обеспечивает распространение эталонного представления данных.

При этом аналитические копии данных не могут являться мастерами.

## Принципы управления данными

* **Единство источника:** Каждый атрибут в любой момент времени имеет только одного авторитетного поставщика данных.
* **Целостность Master-данных:** MDM-система публикует золотую запись; конечные потребители данных не имеют права изменять её локально.
* **Корректировка финансовых данных:** Исправление записей в системах учета выполняется исключительно путем проведения компенсирующих операций.
* **Управление связями:** Таблицы связей хранят все исходные идентификаторы и исключают повторное использование глобальных идентификаторов для старых записей.
