# Задание 2. Мастер-системы и потоки данных

Через три месяца обе группы операционных систем продолжают работать, но получают
единый `customer_id`, управляемые потоки и общую отчётность. Целевые мастера
назначены по доменам, а не централизованы в MDM без разбора.
