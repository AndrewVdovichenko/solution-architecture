# Africa Delivery: Кейс по проектированию архитектуры решения

## Обзор проекта
Данный проект представляет собой кейс по проектированию архитектуры решения для **Africa Delivery** — цифровой маркетплейс-платформы, ориентированной на африканский рынок. Цель проекта — спроектировать масштабируемую, облачную платформу, которая способна эффективно работать в сложных условиях (нестабильное интернет-соединение, разнообразие платежных систем, таких как M-Pesa/Flutterwave, и строгие законы о локализации данных, такие как NDPR/POPIA).

В ходе работы необходимо учитывать противоречивые требования стейкхолдеров, ограниченный бюджет и сжатые сроки разработки MVP (2 месяца), одновременно планируя долгосрочное масштабирование на несколько стран.

## Навигация
Каждая задача включает в себя конкретные архитектурные артефакты (ADR, диаграммы, карты), необходимые для решения бизнес-задач.

- [**Задача 1: Стейкхолдеры и Architecture Canvas**](task1/README.md)
  - Картирование стейкхолдеров, Architecture Canvas и выявление противоречий.
- [**Задача 2: Архитектурное видение и выбор архитектурного стиля**](task2/README.md)
  - Видение архитектуры, записи архитектурных решений (ADR) и контекстные диаграммы C4.
- [**Задача 3: Нефункциональные требования и стратегия доступности**](task3/README.md)
  - Нефункциональные требования (NFR), стратегия обеспечения доступности и наблюдаемости.
- [**Задача 4: Регуляторные ограничения и стратегия данных**](task4/README.md)
  - Соответствие требованиям локализации данных, сравнение облачных регионов и диаграммы развертывания.
- [**Задача 5: MVP Roadmap и Build/Buy/Partner решения**](task5/README.md)
  - Дорожная карта MVP, картирование возможностей и стратегические решения.
