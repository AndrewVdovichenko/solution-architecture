## Принятые решения

Для MVP не устанавливается единая сквозная end-to-end цель доступности в 99.99%. Вместо этого приняты следующие показатели: 99.9% для запросов к каталогу, 99.95% для инициации платежей и событийная цель 99.0% для уведомлений. В вопросах целостности платежей действует политика нулевой терпимости, даже если по доступности еще остается неиспользованный бюджет на ошибки.

Выбранная топология стоимостью \$4,850/мес является максимально возможным уровнем планирования в рамках лимита, установленного CFO. Для проектирования надежной платформы с доступностью 99.99% потребуется бюджет около \$12,500/мес плюс четыре дополнительные штатные единицы (FTE) на платформу и дежурство; при этом такая архитектура все равно не сможет превысить уровень доступности самих провайдеров.
