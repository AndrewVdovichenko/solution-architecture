# Сравнение облачных регионов

## Резюме решения

Ни один из сравниваемых провайдеров не удовлетворяет одновременно и консервативному правилу хранения данных внутри Нигерии, и желаемому уровню зрелости управляемых сервисов. В качестве основного решения для ЮАР и Кении выбрана **AWS Кейптаун**, для изолированной нигерийской ячейки — **Layer3Cloud в Нигерии**, а для обеспечения холодного восстановления в ЮАР и Кении задействован минимальный стек в **GCP Йоханнесбург**. Azure рассматривается как жизнеспособная альтернатива, но не является обязательным компонентом для запуска.

## Сравнительный анализ

Состав планируемой спецификации (BOM) включает: два экземпляра приложения (2 vCPU/4 GB), высокодоступную базу данных (эквивалент PostgreSQL: 2 vCPU/8 GB, 100 GB), 250 ГБ объектного/резервного хранилища, балансировщик нагрузки/WAF, сервис управления ключами/секретами, очередь сообщений, 50 ГБ логов и 2 ТБ исходящего интернет-трафика в месяц. Цены являются оценочными, не включают налоги и комиссии провайдеров за транзакции, и имеют погрешность **±30%**. Поскольку для Layer3 требуется письменное коммерческое предложение по управляемым БД, трафику, межсайтовой репликации, поддержке и восстановлению, итоговая стоимость этого провайдера менее определена.

Значения задержки являются архитектурными ожиданиями на основе географии, а **не результатами измерений**. Перед запуском необходимо провести как минимум 30 HTTPS-запросов из Лагоса, Найроби и Йоханнесбурга в характерные часы работы и зафиксировать медиану/P95 для DNS+TCP+TLS+TTFB. Порогом запуска является время сетевого ответа API P95 ≤ 200 мс для стандартных региональных вызовов; процесс оформления заказа оценивается сквозным методом.

## Оценка топологии запуска

| Компонент | Ежемесячная оценка | Статус в бюджете |
|---|---:|---|
| Региональная ячейка AWS (ЮАР/Кения) | $2,050 | Основной управляемый стек, включает запас мощности |
| Нигерийская ячейка Layer3 | ~$1,700 (заглушка) | Заменить на коммерческое предложение в NGN; включает резерв на две площадки |
| Минимальный холодный стек GCP (Йоханнесбург) | $250 | Хранилище, ключи, периодические вычисления для восстановления; не active-active |
| Общий Edge, зеркало реестра, DNS, синтетические проверки | $450 | Без постоянных персональных данных на глобальном Edge |
| **Итого по планированию** | **$4,450/мес** | Ниже лимита CFO ($5,000) на $550, но погрешность ±30% требует оптимизации трафика/офферов перед запуском |

Если итоговая сумма после подписания превысит \$5,000: сократить объем логов и держать вычисления в GCP выключенными между тестами; **запрещено** убирать локализацию в Нигерии, бэкапы БД, шифрование или механизмы сверки платежей. Любое исключение должно быть одобрено CFO.
