## Резюме принятых решений

- Рабочие нагрузки для Южной Африки и Кении размещаются в региональной ячейке AWS Кейптаун.
- Рабочая нагрузка для Нигерии размещается в изолированной ячейке Layer3Cloud Нигерия; персональные данные нигерийских пользователей, ключи, логи и резервные копии должны оставаться в пределах Нигерии до момента получения юридического подтверждения возможности применения более гибких правил.
- Для Южной Африки и Кении предусмотрена холодная резервная копия в GCP Йоханесбург. Персональные данные граждан Нигерии в эту среду не передаются.
- Из страновых ячеек разрешен экспорт только необратимых минимальных агрегированных данных. Шифрование защищает данные, но само по себе не является юридическим основанием для трансграничной передачи.
- Маркетинговый список из 410 000 контактов помещен в карантин; импорт в продакшн возможен только после подтверждения законности получения согласий и проведения проверок по спискам отписок.
